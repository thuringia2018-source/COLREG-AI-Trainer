# Product Plan

## Product Vision

COLREG AI Trainer is planned as a practical learning tool for deck cadets, OOW officers, Chief Officer candidates, and maritime professionals who want to study COLREG through interactive training instead of only reading static text.

The final product should be simple to use, practical, and focused on real exam preparation.

## Current Stage

The current version is a Python-based test application.

It is used to test:

- Question quality
- Exam logic
- Scenario training
- Oral exam format
- Weak-rule tracking
- Wrong-answer repetition
- Study flow

## Target Users

- Deck cadets
- OOW candidates
- Junior officers
- Chief Officer candidates
- Maritime students
- Seafarers refreshing COLREG knowledge

## Core Product Modes

### 1. Quiz Mode

Multiple-choice questions by rule and category.

### 2. Exam Mode

Timed or untimed exam simulation with score, weak rules, review rules, and strong rules.

### 3. Scenario Mode

Practical navigation situations where the user identifies the applicable COLREG rule and correct action.

### 4. Oral Exam Mode

Question-and-answer practice for maritime oral exams.

### 5. Weak Rules Training

Focused practice on rules where the user performs poorly.

### 6. Repeat Wrong Answers

A learning loop that allows the user to repeat mistakes from the last exam or previous quizzes.

## Future Web App

The commercial version should become a browser-based app so users do not need Python.

Planned web app features:

- Clean user interface
- Mobile-friendly layout
- Login/account system
- Progress tracking
- Rule-by-rule study dashboard
- Exam history
- Certificate-style completion summary
- Exportable study report

## Important Disclaimer

This product is for education and exam preparation only.

It does not replace:

- Official COLREG text
- Company SMS
- Flag-state requirements
- Master’s standing orders
- Bridge procedures
- Professional judgement at sea
