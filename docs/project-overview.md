# Project Overview

COLREG AI Trainer is an educational training tool for learning and practising the International Regulations for Preventing Collisions at Sea.

The project is designed for:

- Deck cadets
- OOW officers
- Chief Officer candidates
- Maritime students
- Professional mariners refreshing COLREG knowledge

The app includes quiz training, scenario practice, oral exam preparation, weak-rule tracking, and repeated wrong-answer training.

The current Python test version is COLREG Trainer v1.3.6.

The future goal is to create a web-based trainer that can be used easily by students and seafarers without requiring Python knowledge.
