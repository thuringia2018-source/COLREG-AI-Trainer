# Changelog v1.7

## COLREG Trainer v1.7 — Stable Verified Preview

This version represents the first stable and verified Python learning-engine version of COLREG AI Trainer.

The question bank and media training logic were reviewed and tested against the COLREG Consolidated 2018 rules.

## Main Improvements

- Added Annex I–IV training content
- Expanded sound signal training
- Expanded lights and shapes training
- Added Annexes / Technical Details category
- Improved sound signal context
- Improved Rule 35 sound signal accuracy
- Added bell and gong questions
- Added distress signal questions
- Added SOS and MAYDAY training references
- Added COLREG Coverage Report
- Confirmed Rules 1–38 coverage
- Added Rules 39–41 compliance background
