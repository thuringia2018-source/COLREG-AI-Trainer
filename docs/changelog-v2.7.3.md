# Changelog v2.7.3 — Expanded Visual Pack

## Summary

Version v2.7.3 expands the COLREG AI Trainer visual training system with additional scenario illustrations, distress signal visuals, and Lights & Shapes / special vessel training cards.

This version continues the transition from a standard quiz application into a visual candidate-exam training system.

## Main Additions

### Collision Avoidance Visual Cards

Added new visual training cards for practical COLREG scenario recognition, including:

- Crossing situations
- Give-way vessel action
- Stand-on vessel action
- Head-on situations
- Overtaking situations
- Narrow channel scenarios
- Traffic Separation Scheme crossing
- Risk and no-risk visual comparison

### Distress Signal Visual Cards

Added visual recognition cards for distress signal training, including:

- NC flag signal
- Orange smoke
- Red hand flare
- Rocket parachute flare
- Square flag and ball signal

### Lights & Shapes / Special Vessel Visual Cards

Added selected visual cards for:

- Diving operations / Alpha flag
- Mineclearance day shapes
- Dredging / underwater operations day shapes
- Towing over 200 meters

## Candidate Mode Preserved

Candidate Mode remains active in the Collision Avoidance section.

Before answering, the candidate does not see:

- Rule number
- Scenario title
- Filename
- Explanation

The candidate must identify the situation from the image itself.

## Full Image Display Preserved

The image display correction from v2.7.2 is preserved.

Illustrations are shown in full without cropping, so important details remain visible:

- Relative vessel position
- Wake direction
- Vessel heading
- Day shapes
- Restricted visibility cues
- TSS and narrow channel layout

## Review Handling

Images that are not yet suitable for final quiz use are kept outside the main candidate flow and reserved for review.

Only accepted images should be used in exam-style training.

## Development Notes

v2.7.3 is a visual content milestone. The next major upgrade should focus on exam logic rather than simply adding more images.
