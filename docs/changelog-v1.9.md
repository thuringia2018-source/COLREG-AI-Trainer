# Changelog v1.9

## COLREG Trainer v1.9 — First SVG Vessel Illustrations

This version adds the first original SVG vessel illustration structure for future web application development.

The Python trainer remains fully functional, while the project now includes original SVG training graphics for lights and shapes.

## Main Improvements

- Added 40 original SVG vessel illustration files
- Added `media/svg/` illustration structure
- Added new menu option: SVG Vessel Illustration Report
- Web-ready Data Report now checks SVG illustration count
- Preserved verified v1.8 web-ready data structure
- Preserved v1.7 verified COLREG learning engine logic

## SVG Illustration Purpose

The SVG files are intended for the future web version of COLREG AI Trainer.

They will support:

- Lights and shapes visual trainer
- Vessel identification exercises
- Different vessel status illustrations
- Future web/mobile training screens

## Important Note

The SVG illustrations are simplified educational graphics.

They are original project assets and are not copied from external books, websites, or copyrighted images.

## Status

Stable SVG preview version.

This release prepares the project for the next development stage: first web app prototype.
